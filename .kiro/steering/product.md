# product.md — ビジ友（bijiyu）

## サービス概要

ビジ友は、建設業界における**職人（受注者）と発注者をつなぐWebマッチングサービス**。仕事を探す職人と、職人を探す発注者が、職種・エリアなどの条件で検索・マッチングし、メッセージでやり取りして仕事につなげる。

**参考サービス**: 助太刀（suke-dachi.jp）— アプリ中心の建設業マッチング。ビジ友はWebサービスとして展開し、デザイン・機能体系は独自。

## ユーザーロール

### 受注者（Contractor）

- 仕事を探す職人
- 無料プランで利用可能
- 案件検索、応募、メッセージ（月5通制限）、プロフィール公開

### 発注者（Client）

- 職人を探して仕事を発注するユーザー
- 有料プラン（ライトプラン〜）で利用可能
- 案件掲載、職人検索、メッセージ、マッチング管理

### ロールアップグレード

- 受注者が有料プランに課金すると**発注者機能が解放**される
- **1アカウントで受注・発注の両方が可能**

### 管理者（Admin）

- サービス運営者
- ユーザー管理、案件モデレーション、課金管理、レポート

## ビジネスモデル

サブスクリプション課金。無料プラン＋有料4プラン構成。

| 補償 ¥9,800（受注者向け）**【販売停止中】** | 9,800円/月 | 月額（Stripe subscription） | 報酬未払いトラブル発生時、最大500万円までの補償。同上 |

- **単発オプション**（急募・動画掲載）: Stripe Checkout の `mode: 'payment'` で処理。subscription_id は持たない
- **月額オプション**（補償）: Stripe Checkout の `mode: 'subscription'` で処理。Webhook で自動更新
- **補償オプションの位置付け**: 受注者（職人）が現場で発生した報酬未払いトラブルに備える保険。**全 contractor および client（owner）が購入可能**（無料の受注者も含む）。基本プランの加入要件はなく、基本プランから独立して契約・継続される（基本プラン解約後も補償は自動キャンセルされない）。staff（法人代理アカウント）と admin は購入不可（契約主体は本人単一）

### プランの位置づけ

- **無料**: 受注者機能のみ。仕事を探す職人向け
- **ライト（¥3,800）**: 発注機能が解放。個人事業主レベル
- **スタンダード（¥14,800）**: 現場掲載が無制限に。小規模法人向け
- **プレミアム（¥48,000）**: 複数人利用（10人）、代理メッセージ対応
- **ハイエンド（¥148,000）**: 複数人利用（30人）、代理メッセージ大量対応

### お支払い方法（2026-09 P2 で銀行振込を追加）

| 方法 | 対象 | 流れ |
|---|---|---|
| クレジットカード（Stripe） | 基本プラン（月払い / 年払い、P3）・全オプション | Stripe Checkout → Webhook で即時有効化。**アップグレード（上位プラン / 月払い→年払い）は Stripe のホスト画面（Customer Portal `subscription_update_confirm`）で確定**し、日割り差額・次回請求は Stripe が表示。ダウングレード（下位プラン / 年払い→月払い）はアプリ内ダイアログで期末切替を予約。解約もアプリ内（CLI-026） |
| 銀行振込 | 基本プラン（月払い / 年払い）・全オプション（補償は月払い / 年払い） | **P9（2026-09）: 会員側の申込ボタンは既定で非表示**（`NEXT_PUBLIC_BANK_TRANSFER_SELF_SERVICE_ENABLED` 未設定）。料金画面と FAQ・特商法で「銀行振込をご希望の方はお問い合わせください」と案内 → 会員がお問い合わせ（「お支払い方法（銀行振込）について」）→ 運営が ADM-025「申込を登録する」で代理登録（申込者控えメールのみ送信）→ 請求書送付（アプリ外）→ 入金（アプリ外）→ ADM-026 で有効化 → 有効化メール。フラグを `true` にすると従来の本人申込（CLI-026 のボタン → メール 2 通）に戻る |

- 銀行振込の請求書・振込先・支払期限は **アプリで管理しない**（会計ソフト等）。アプリは申込レコードの状態（申込受付 → 請求書送付済 → 入金確認済 / 取消）だけを持つ
- 有効期限 = 利用開始日 + 1 か月（年払いは + 1 年）の前日。**期限が来ても自動停止しない**（D3）。管理画面に「期限間近（30 日以内）/ 期限切れ」バッジ、30 日前・当日に運営宛通知メール。継続は入金確認後に ADM-004「期限を延長する」
- 銀行振込契約のプラン変更・解約は運営が ADM-004 で行う（ユーザー画面からは不可）。Stripe 契約中の会員が銀行振込へ切り替える場合は、Stripe の期間終了日の翌日を利用開始日にして有効化する（D8。二重契約は DB 制約で防止）
- 初回事務手数料 20,000 円は Stripe と同じ条件（初めての基本プラン契約時のみ）
- 年払い金額は **暫定で月額 × 12**（`YEARLY_PRICE_TAX_INCLUDED`）。正式金額が決まったら定数と Stripe の年額 Price（`scripts/stripe/setup-yearly-prices.mjs` の `YEARLY_AMOUNTS`）を同時に更新する
- **サイクル切替ルール（P3）**: 月払い → 年払い = 即時（アップグレード扱い、Stripe ホスト画面）。年払い → 月払い = 次回更新日に切替（ダウングレード扱い、予約）。プランのランク差があればランクが優先（`comparePlanChange`）
- Stripe の Price は月額 4 + 年額 4 の 8 本。環境変数 `STRIPE_PRICE_*` / `STRIPE_PRICE_*_YEARLY`。プラン変更確認用のポータル設定は `STRIPE_PORTAL_UPDATE_CONFIGURATION_ID`（既存の `STRIPE_PORTAL_CONFIGURATION_ID` = カード更新・請求履歴とは別）

### プラン機能の補足

- **興味あり**: マイリスト登録（♡ボタン）と同一機能。全プラン無制限
- **代理メッセージ**: ビジ友の運営スタッフ（サービス提供側の人間）が、法人の発注者に代わってメッセージを送信する機能。法人組織内に代理アカウント（担当者権限、`is_proxy_account = true`、1法人1つ）を作成し、運営スタッフがそのアカウントにログインして操作する。通数の上限はシステムでは制御しない（運用管理）
- **無料ユーザーの応募制限**: 案件の検索・閲覧は全件可能。ただし応募は「自分の登録職種」かつ「自分の登録県」に合致する案件のみ可能。合致しない案件は詳細画面で応募ボタンが非活性になる（有料プランに加入すると全案件に応募可能）
