# 修正依頼: 会員画面の動画表示枠のサイズ統一（P4/P10 フォローアップ）

作成: 2026-09-15。依頼者: クライアント担当（ぴにょ）。起票の経緯はローカル環境での 2026-09 改修の目視確認（staging 反映前デモ準備）。
対象ブランチ: `feature/spec-changes-202608`（または staging マージ後の同系フォローアップとして）。

## 1. 事象（ローカルで確認済み）

ユーザー詳細ページの動画一覧（`<VideoList />`、P4 で実装）で、動画ごとに表示枠の大きさがバラバラに見える。

再現手順:
1. ADM-027 で同一ユーザーに動画を 2 本登録する
   - 1 本目: URL 埋込（TikTok）
   - 2 本目: MP4 アップロード（Cloudflare Stream、横向きで撮影した動画）
2. 会員側のユーザー詳細（または本人のユーザープロフィール）で動画欄を見る

結果:
- URL 埋込（TikTok）は縦長（スマホ比率）の大きな枠で表示される
- Cloudflare の動画は元動画の縦横比のまま表示されるため、横向き動画だと枠が低く「小さく」見える
- 2 本が縦に並ぶと大きさの差が目立ち、ページの見た目が不揃いになる

## 2. 原因（推定）

不具合ではなく仕様上の挙動:
- TikTok 等の外部埋込（`src/lib/video-embed.ts` の PATTERNS 経由）は埋込プレーヤー側の固定比率
- Cloudflare Stream プレーヤーは動画の実寸比率で描画される

つまり「埋込元ごとに枠のルールが違う」ことが原因。

## 3. 依頼内容

会員向け表示（`<VideoList videos label />` を使う全画面）で、**動画の種類・縦横比によらず表示枠の大きさを統一**してほしい。

要件:
- URL 埋込（TikTok 等）と Cloudflare アップロードの両方に同じ枠ルールを適用する
- 枠に収まらない比率の動画は、切り取らずに収める（レターボックス / contain 相当）方向を希望
- レスポンシブ対応（SP でも枠が揃って見えること）
- 表示のゲート条件は変えない（オプション購入有無で出し分けない = 承認済み D4 を維持）
- ADM-027（管理画面）のプレビューは対象外でよい（会員向け表示のみ）

### 要確認（クライアントに確認してから実装したい点）

- 統一する枠の基準比率: 縦長（9:16、TikTok に合わせる）か、正方形か、横長（16:9）か
  - 参考: 現状の登録動画はスマホ縦動画が主になる想定のため、縦長基準が有力と思われる

## 4. 実装時の注意（CLAUDE.md 準拠）

- スタイルは Tailwind ユーティリティのみ。カスタム CSS・インラインスタイル禁止
- `frame-src` CSP（`src/middleware.ts`）や `PATTERNS`（`src/lib/video-embed.ts`）の変更は不要のはず（表示枠のみの変更）
- 表示ロジック変更のため、関連 E2E（`e2e/video-display.spec.ts`）の期待値に影響がないか確認すること
- 対象コンポーネント: `VideoList`（P4 実装。`src/components/` 配下。`getReadyVideos()` → `<VideoList videos label />` の表示 1 パターンに統一されている）

## 5. 優先度・タイミング

- 優先度: 低〜中（機能は正常動作。見た目の統一のみ）
- staging 反映（B5）をブロックしない。反映後のフォローアップ修正で構わない
- クライアント打ち合わせ（2026-09-15 予定）で表示を見せた際の反応次第で、基準比率を確定してから着手
